## Evidence rules and how to read this ledger

- **REPO-VERIFIED:** Source, source call paths and/or tests directly inspected in the published fork at its pinned SHA. Establishes the code's **mechanism**, not that a local executable was run.
- **UPSTREAM-VERIFIED:** Direct code/source examined in a separate pinned implementation or GitHub compare. The quality effect is still unmeasured.
- **DOCUMENTED:** Official product, API, architecture, changelog or maintainer claim; where proprietary internals are unavailable, do not infer implementation details.
- **THIRD-PARTY:** Independent research, survey or observed comparison with unverified generalizability.
- **INFERRED:** A conditional consequence deduced from inspected code/documents, with counterexamples explicitly retained.
- **UNKNOWN:** Missing or conflicting evidence, especially local runtime, task success, historical provider billing, peer benchmark parity and user session traces.
- **MEASURED:** Reproducible executed empirical analysis with controlled run conditions and uncertainty. **There are no MEASURED entries in this execution.**

`Verified on` is the inspection date, **not** a claim that the underlying source was last changed that day. For GitHub files, stable anchor links specify the full pinned SHA; a URL that points to `main`/`master` alone is intentionally classified as current **documentation/source at inspection** and less reproducible. Third-party restatements of an official release are not independent evidence.

### Key source excerpts paraphrased as testable statements

**E-006 + E-007 + E-009 conditional failure path:** No policy row → `get` returns `undefined` → default standard decision does not write an explicit variant → early no-change return in `EffortTransition.apply` → a failed configured verifier reaches `setOpenFailure`, which only updates existing rows → no new state → later escalation decision sees no recorded failure. This is reproducible as a *source-path deduction* without fabricated test output. One alternative remains: another root-initialization mechanism not discovered in this bounded inspection. Tests examined first insert the row, which explains why the gap may escape current test coverage.

**E-010 + E-011 + E-012 background path:** A shell action can return status running and no terminal numeric `exit`; the later job result is a synthetic session event carrying final status. The policy observer in `SessionStep` gets tool-settlement metadata at the initial result; no direct observer call is shown in the notification handler. Additional subscribers were **not** comprehensively enumerated, so the conclusion is probable rather than proven across every runtime path.

**E-004 + E-005 + E-013 context lesson:** Compaction, cache-aware prefix construction and read/write token accounting are visibly implemented. High context tokens and high cache-hit ratios do not identify irrelevant content, wasted work or a broken compactor. Without objective task acceptance and prompt composition, the cause is unknown.

### D. Independence and source-quality controls

**One evidentiary lineage, not multiple votes:** A DeepSeek vendor release, its translated announcement and a partner blog repeating its score are **not independent replications**.
